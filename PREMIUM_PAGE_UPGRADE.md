# EstateHUB Premium Page Upgrade

This version upgrades the visual presentation of the pages other than the property catalogue:
- Home
- Login
- Register
- Communities
- About
- Bookings
- Property Details
- Shared navbar/footer

The existing Angular/Node/MongoDB architecture and property catalogue functionality were preserved. No MongoDB connection configuration was changed.

Run the project as before:
1. Copy your working `server/.env` into `server/.env`.
2. In `server/`: `npm install` then `npm start`.
3. In `client/`: `npm install` then `npm start`.
